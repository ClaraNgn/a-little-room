# The Abroad Chapter

A cozy interactive story about Jenny, a student from Vietnam preparing to study in the United States.

## Chapter 1 — Beginnings

Meet Jenny in the lobby, then help her pack six meaningful objects on the night before her flight. Explore the full-screen room, read her messages in the chat, and drag or select objects to pack her suitcase.

English-only. Supports keyboard controls, touch, optional music and local progress saving. On narrow screens, swipe or use the look-around buttons to explore the room.

This prototype currently includes the lobby, introduction and Chapter 1. Jenny is a fictional avatar. Artwork includes AI-generated assets developed from the creator’s art direction.

## Run locally

Serve this folder with any static HTTP server; no build step or API key is required. Progress is saved only in the visitor’s browser when storage is available.
